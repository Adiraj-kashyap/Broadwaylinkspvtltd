# Broadway Links Pvt. Ltd. (BLPL) - Corporate Web Portal

A premium, high-performance corporate website designed for **Broadway Links Pvt. Ltd.**, a leader in India's construction and infrastructure sector (Highways, Bridges, Oil & Gas, Irrigation).

This project modernizes BLPL's digital presence with a responsive, interactive, and visually striking user interface, showcasing their 23+ years of excellence, ₹2200Cr+ completed works, and massive fleet of 200+ equipment assets.

## 🚀 Key Features

*   **Modern Hero Section**: Immersive aesthetics with animated entrance effects and premium typography.
*   **Dynamic Fleet Management**: A comprehensive, searchable, and filterable catalog of the company's 300+ heavy machinery assets (JCB, Tata, Ashok Leyland, etc.).
*   **Interactive Project Showcase**: Detailed portfolio of Ongoing/Completed projects with categorization (Roads, Bridges, Industrial).
*   **Performance & SEO**: Built on Next.js for lightning-fast page loads, optimized metadata, and semantic HTML structure.
*   **Premium UI/UX**: Custom "Yellow Glow" interaction theme, smooth `Framer Motion` animations, and responsive layouts for all devices.
*   **Live Brand Integration**: Integration of real partner and fleet brand assets (Indian Oil, NHAI, Punj Lloyd, etc.).

## 🛠️ Technology Stack

*   **Framework**: [Next.js 14+](https://nextjs.org/) (React)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/)
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **UI Components**: Custom components built on Radix UI primitives.

## 📦 Installation & Deployment

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/blpl-web.git
    cd blpl-web
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Run locally**:
    ```bash
    npm run dev
    ```
    Visit `http://localhost:3000` to view the application.

4.  **Build for Production**:
    ```bash
    npm run build
    npm start
    ```
